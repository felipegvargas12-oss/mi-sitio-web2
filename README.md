# Gaming World

## Descripción
Página web sobre videojuegos que muestra juegos populares, noticias y un formulario de contacto.

## Tecnologías
- HTML5
- CSS3 (Flexbox)

## Estructura
- index.html
- css/styles.css
- images/

## Prompts utilizados
1. "Crear estructura HTML5 semántica"
   → Para organizar el sitio correctamente.

2. "Ejemplo de Flexbox en navegación"
   → Para hacer el menú horizontal.

3. "Diseño CSS para tarjetas de juegos"
   → Para mostrar juegos de forma ordenada.

4. "Formulario HTML5 simple"
   → Para crear la sección de contacto.
   
5. "Diseño de la pagina web moderno con colores parecidos a la pagina de Steam"
   → Para editar el diseño completo de la pagina web y hacerlo más comoda a la vista del usuario.
