# World of Gaming

## Descripción del Proyecto
Al proyecto se le incorporaron funcionalidades dinámicas utilizando JavaScript.

El sitio permite visualizar juegos populares, buscar juegos en tiempo real y agregar juegos a una lista de favoritos, aplicando manipulación del DOM y lógica de programación.

│     ├── juego2.jpg
│     ├── juego3.jpg
│     ├── juego4.jpg
│── js/
│     └── main.js
│── index.html
│── README.md

## Funcionalidades JavaScript

### 1. Render dinámico de juegos
Los juegos se generan dinámicamente desde un arreglo de objetos mediante JavaScript.

### 2. Sistema de favoritos
El usuario puede agregar juegos a una lista de favoritos mediante un botón.  
Los juegos seleccionados se almacenan en una sección independiente.

### 3. Buscador dinámico
Se implementa un buscador en tiempo real, el cual filtra los juegos según el texto ingresado por el usuario.

### 4. Manipulación del DOM
Se utilizan:
- `querySelector` para seleccionar elementos
- `addEventListener` para eventos
- `innerHTML` para modificar contenido dinámicamente

## Validaciones y Correcciones Realizadas

Durante el desarrollo del proyecto se realizaron las siguientes mejoras y correcciones:

- Corrección de errores de códigos duplicados y caracteres incorrectos.

- Ajuste en la manipulación del DOM para asegurar que los elementos se rendericen correctamente.
- Verificación de rutas de imágenes para evitar errores de carga.
